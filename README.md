# slot — бронирование игровой зоны

Учебный full-stack проект: сайт для бронирования мест в игровой зоне (ПК, PS5, VR, приват-комната).

**Стек:** React, Vite, React Router DOM, Firebase (Authentication + Firestore), нативный CSS.


## Возможности

- Регистрация, вход, выход, восстановление сессии после перезагрузки.
- Публичный каталог 11 мест с поиском, фильтрами и сортировкой.
- Динамическая страница места `/places/:id`.
- Личный кабинет `/dashboard` со списком броней, фильтром по статусу и удалением.
- Создание брони `/bookings/new` с выбором дня, времени и места на плане этажа.
- Редактирование `/bookings/:id/edit`.
- Карточка брони `/bookings/:id` с кодом и статусом.
- Страница `/explore` с внешним API (CheapShark) — скидки на игры в Steam.
- Страницы 403 и 404.
- Светлая и тёмная тема с сохранением выбора.
